## 🚀 How to Run & Edit in VS Code

1. **Extract the ZIP file** to any folder on your laptop.
2. Open **VS Code** (`File` -> `Open Folder...` -> Select `sonu_verma_java_practicals`).
3. If you have the **Live Server** extension installed in VS Code:
   - Right-click `index.html` and choose **"Open with Live Server"**.
4. Or simply **double-click `index.html`** in your file manager to open it in Chrome, Edge, or Brave.

## 🌐 How to Host Online (Free & Instant)

### Option 1: Vercel (1-Minute Deploy)
1. Go to [vercel.com](https://vercel.com).
2. Drag and drop this extracted project folder onto Vercel.
3. Your website is instantly live with a free `.vercel.app` URL!

### Option 2: GitHub Pages
1. Create a repository on GitHub named `java-practicals`.
2. Push or upload these files directly into the repository.
3. Go to **Settings** -> **Pages** -> Select branch `main` / `root` -> Click **Save**.
4. Your website will be hosted at `https://<username>.github.io/java-practicals/`.

### Option 3: Netlify Drop
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the folder. Done!
